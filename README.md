# House Price Prediction using Linear Regression

## Project Overview

This project uses **Supervised Machine Learning (Linear Regression)** to predict house prices based on various property features such as location, size, condition, construction details, and basement area.

The goal is to build a regression model that can estimate the selling price of a house using historical housing data.

---

## Dataset Features

The dataset contains the following features:

* Id
* MSSubClass
* MSZoning
* LotArea
* LotConfig
* BldgType
* OverallCond
* YearBuilt
* YearRemodAdd
* Exterior1st
* BsmtFinSF2
* TotalBsmtSF

### Target Variable

* SalePrice

## Machine Learning Workflow

1. Load the dataset
2. Handle missing values
3. Convert categorical features into numerical values
4. Split data into training and testing sets
5. Train a Linear Regression model
6. Make predictions
7. Evaluate model performance using:

   * R² Score
   * Mean Absolute Error (MAE)
   * Root Mean Squared Error (RMSE)

---

## Model Used

**Linear Regression**

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values.
